---
Source code for paper "Randomized Algorithms for Large-Scale Dictionary Learning"
---
### 1. Running Environment

Matlab

### 2. Introduction to the code

RAODL.m : Algorithm 5: A Randomized Algorithm for over-complete and complete Dictionary Learning (m>=n)
RAUDL.m : Algorithm 5: A Randomized Algorithm for under-complete Dictionary Learning (m<n)
RAKDL.m : Algorithm 6: A Randomized algorithm for kernel dictionary learning
RALDL_train.m : RALDL for the training phase of image classification
RALDL_classify.m : RALDL for the testing phase of image classification
RAKDL_train.m : RAKDL for the training phase of image classification
RAKDL_classify.m : RAKDL for the testing phase of image classification
exp1_1_RAODL.m : Numerical Experiments. Performances on representation error (RAODL)
exp1_2_RAUDL.m : Numerical Experiments. Performances on representation error (RAUDL)
exp1_3_RAKDL.m : Numerical Experiments. Performances on representation error (RAKDL)
mydenoisedemo.m : Numerical Experiments. Image denoising (Cameraman, Pirat, Jetplane, House and Peppers)
mydenoisedemo_20240630.m : Numerical Experiments. Image denoising (Stockton, Richmond, Shreveport, Oakland, and wash-ir)
digit_new_1.m : Numerical Experiments. First experiment of digital recognition
digit_new_2.m : Numerical Experiments. Second experiment of digital recognition
digit_new_3.m : Numerical Experiments. Third experiment of digital recognition
facerecog : Numerical Experiments.  Object and face recognition

Run demo.m.
